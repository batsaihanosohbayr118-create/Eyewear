# AERIS — Люкс нүдний шилний вэбсайт

Next.js 14 (App Router) + TypeScript + Tailwind CSS дээр бүтээсэн, админ
удирдлагатай люкс нүдний шилний брэндийн танилцуулга сайт.

## Эхлэх

```bash
npm install
cp .env.example .env.local   # аль хэдийн хийгдсэн, зөвхөн утгыг өөрчил
npm run dev
```

Сайт: http://localhost:3000
Админ: http://localhost:3000/admin/login

`.env.local` доtorх `ADMIN_PASSWORD`-г өөрийн нууц үгээр солиорой
(анхны утга: `changeme123`). `SESSION_SECRET`-г мөн санамсаргүй урт
мөрөөр солино уу.

## Агуулгыг өөрчлөх

Компанийн нэр, лого, холбоо барих мэдээлэл, сошиал холбоос бүгд нэг
файлд байна:

```
content/site.ts
```

Энэ файлыг засахад бүх хуудсанд шууд шинэчлэгдэнэ — хаана ч
хатуу код (hardcode) байхгүй.

## Бүтээгдэхүүн удирдах

`/admin` дотор нэвтэрч:

- Бүтээгдэхүүн нэмэх / засах / устгах
- Зураг байршуулах (эсвэл URL шууд оруулах)
- Ангилал, нэр, тайлбар, үнэ, "онцлох" төлөв өөрчлөх

Бүтээгдэхүүний өгөгдөл `data/products.json` файлд, байршуулсан
зурагнууд `public/uploads/` дотор хадгалагдана — жижиг, хурдан эхлэхэд
зориулсан энгийн шийдэл.

## ⚠️ Deploy хийхийн өмнө мэдэх зүйл

Энэ төсөл JSON файл дээр суурилсан "мэдээллийн сан" ашигладаг тул:

- **Local сервер эсвэл VPS/Docker дээр (жишээ нь өөрийн сервер,
  Railway, Render)** — бүрэн ажиллана, админаас хийсэн өөрчлөлт
  байнга хадгалагдана.
- **Vercel зэрэг serverless орчинд** — файлын систем ажиллах үед л
  бичигддэг (ephemeral), өөрөөр хэлбэл deploy хооронд админаас хийсэн
  засвар, шинэ зураг устаж магадгүй. Vercel дээр байнгын хадгалалт
  хэрэгтэй бол:
  - Бүтээгдэхүүний өгөгдлийг Postgres/Supabase/PlanetScale зэрэг бодит
    мэдээллийн санд шилжүүлэх
  - Зургийг Vercel Blob, Cloudinary, S3 зэрэг файлын хадгалалтад
    байршуулах

Эхлээд туршиж, дараа нь хэрэгцээ гарвал дээрх сольж болно — одоогийн
бүтэц үүнд бэлэн (`lib/db.ts` дотор л өөрчлөлт хийхэд хангалттай).

## Технологи

- Next.js 14 (App Router, Server Components)
- TypeScript
- Tailwind CSS
- `jose` — админ сешн (signed JWT, httpOnly cookie)
- `nanoid` — ID болон файлын нэр үүсгэх

## Фонт

Google Fonts-с Playfair Display, Manrope, IBM Plex Mono ашигладаг
(Cyrillic дэмждэг тул монгол хэл зөв харагдана). `npm run build`
үед интернэт холболт шаардлагатай — Vercel зэрэг платформ дээр
асуудалгүй ажиллана.
